# java-estudos
Minha jornada de estudos em Java, do zero ao desenvolvimento backend.
## Objetivo
Registrar minha evolução no aprendizado Java, começando pelos fundamentos de de lógica de programação e avançando gradualmente até o desenvolvimento backend.
## Conteúdos estudados
- Estrutura básica de um programa Java
- `System.out.println`
- Variáveis
- `int`
- `double`
- `char`
- `String`
- `boolean`
- `Scanner`
- Operadores matemáticos
- `if`
- `while`
- `for`
## Evolução
Este repositório acompanha minha evolução desde os primeiros exercícios em Java.
A proposta é registrar cada etapa do aprendizado, mantendo o histórico de exercícios, práticos e projetos desenvolvidos ao longo dop tempo.

- Aprender orientação a objetos

- Estudar banco de dados e SQL
